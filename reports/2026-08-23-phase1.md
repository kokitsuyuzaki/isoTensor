## Matrix modelとMU更新式

min_{B≥0} ½‖X−AB‖²_F(Aは固定)。勾配から再導出:
∇_B f = AᵀAB − AᵀX(両項とも非負なので自然に正負分解)、よって

    B ← B ⊙ (AᵀX) / (AᵀAB + ε)

提示された式と一致し、Lee–Seung Frobenius NMFのfixU版と等価
(補助関数論法で目的関数の単調非増加が保証)。
Aが固定なのでAᵀXとAᵀAはループ外で1回だけ計算し、
1反復のコストはNに依存しない(O(C²I))。

## Synthetic testの結果

- Noiseless (N=5, C=2, I=6): 約406反復で収束、
  max|B̂ − B_true| ≈ 5.3×10⁻¹⁵(機械精度で完全復元)。
  Aがfull column rankなら大域解が一意にB_trueになるため理論とも整合
- 目的関数履歴: `RecError`が全反復で単調非増加(テストで検証)
- Noisy (sd=0.05): Bの相対誤差 ≈ 3.2%、残差 ≈ ノイズ水準
  (0.294 vs 理論値0.274)
- 単一cell typeでは閉形式の最小二乗解との一致も検証

## Tensor modelの推奨案(notes/tensor-model.mdの要約)

4候補を identifiability / 解釈性 / パラメータ数 / MU導出 /
matrix modelとの関係 で比較。
推奨は partial non-negative Tucker(cell type mode非圧縮)、
B_nci = Σ_pq U_np G_pcq W_iq の形。

- CP: identifiabilityは最良(Kruskal条件)だが、cell type軸がV内で混合され
  「圧縮しない」方針に反する。matrix modelのnestingも不自然
- Full Tucker: cell type modeを圧縮してしまい設計方針に反するので棄却
- Shared + deviation: 解釈性は最良だが、centering制約が非負性と両立せず
  (非負加法偏差は上方向のみ)、MUが自然に導けない
- Partial Tucker: R_N=1, U=1_Nでmatrix modelを厳密に含み、
  MUもブロックごとのNNLS+MMで自然に導出可能

追加提案: Uの第1列を1_Nに固定しPhase 1のB̂で対応するcore sliceを
warm-start(= population成分 + 非負のindividual偏差)。
最大の論点は「偏差が上方向のみ」の制約が生物学的に許容できるか。
notes/tensor-model.md末尾にレビュー用open questions
(符号付き偏差の要否、per-gene simplex制約、KL divergence化)あり。

APIはnnTensor::NTDの`rank=c(...)`+`modes=`方式より、
提案どおり`rank_individual`/`rank_isoform`を推奨。
